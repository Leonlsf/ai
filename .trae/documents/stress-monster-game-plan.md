# 压力怪兽 (Stress Monster) - 游戏开发计划

## 概述

一款以「吞噬压力」为核心的减压游戏。玩家将烦心事输入游戏，它们会变成食物被可爱的怪兽吞噬。怪兽吃得越多越开心，还会根据饮食进化出独特形态。融合喂食爽感、情绪转化、Boss战和进化系统，打造一个真正能宣泄压力的互动体验。

## 设计决策

| 决策项 | 选择 |
|--------|------|
| 核心玩法 | 喂食为主 + Boss战 |
| 情绪系统 | 4种情绪转化（愤怒/焦虑/悲伤/烦躁） |
| 进化方式 | 根据饮食进化，每个玩家怪兽独一无二 |
| 美术风格 | 萌系卡通 |
| 技术方案 | Unity C# |
| 目标平台 | 双端兼容（手机 + PC） |

## 系统一：基础喂食系统

### 玩法描述
- 屏幕中央是怪兽，下方是输入区域
- 玩家输入压力来源（如"加班""考试""堵车"），文字变成对应食物飘到屏幕上
- 玩家拖拽食物到怪兽嘴边，怪兽张嘴吞噬
- 吞噬瞬间：屏幕震动 + 粒子爆发 + 满足音效 + 怪兽表情变化
- 连续喂食触发Combo，Combo越高特效越华丽

### 交互细节
- **手机端**：触摸拖拽食物到怪兽嘴边
- **PC端**：鼠标拖拽或点击食物自动飞向怪兽
- 怪兽状态：饥饿（张嘴期待）→ 咀嚼（闭眼享受）→ 饱足（拍肚皮打嗝）→ 再次饥饿

### 预制压力词库
- 工作：加班、KPI、会议、996、裁员、通勤、打卡
- 学习：考试、作业、论文、挂科、答辩
- 生活：堵车、排队、账单、失眠、减肥、社交
- 情感：吵架、分手、被误解、被忽视

## 系统二：情绪转化系统

### 4种情绪类型及转化效果

| 情绪 | 食物形态 | 怪兽反应 | 视觉特效 | 技能效果 |
|------|----------|----------|----------|----------|
| 愤怒 😠 | 辣椒 🌶️ | 脸红喷火 | 火焰粒子 + 屏幕边缘发红 | 喷火清扫屏幕上所有食物 |
| 焦虑 😰 | 柠檬 🍋 | 触电颤抖 | 闪电粒子 + 屏幕抖动 | 电击加速食物生成速度 |
| 悲伤 😢 | 苦瓜 🥒 | 下雨治愈 | 雨滴粒子 + 彩虹出现 | 治愈雨恢复怪兽饱食度 |
| 烦躁 😤 | 炸药 🧨 | 爆炸兴奋 | 爆炸粒子 + 屏幕震动 | 爆炸一次吞噬范围内所有食物 |

### 情绪识别规则
- 关键词匹配：预设情绪关键词库
- 玩家手动选择：输入后弹出4个情绪图标供选择
- 混合情绪：部分词可触发混合效果（如"又加班又吵架"→ 愤怒+烦躁 = 火焰爆炸）

## 系统三：Boss战

### Boss设计

#### Boss 1：内卷兽
- **外观**：巨大的人形怪物，穿着西装，头上长角，手持KPI报表
- **攻击方式**：向玩家投掷"deadline"炸弹，屏幕出现倒计时
- **弱点**：愤怒类食物伤害加倍（内卷最怕愤怒反击）
- **击败特效**：西装碎裂，变成小怪兽逃跑

#### Boss 2：焦虑蛛
- **外观**：蜘蛛形态，网由无数"万一"文字编织而成
- **攻击方式**：吐丝困住怪兽，需要快速点击挣脱
- **弱点**：悲伤类食物（治愈雨溶解蛛网）
- **击败特效**：蛛网断裂，化为光点消散

#### Boss 3：拖延怪
- **外观**：史莱姆形态，不断膨胀，身上写满"明天再说"
- **攻击方式**：逐渐占据屏幕空间，压缩怪兽活动区域
- **弱点**：烦躁类食物（爆炸炸开拖延怪）
- **击败特效**：爆裂成无数小史莱姆四散奔逃

### Boss战流程
1. 喂食积累能量条，满后触发Boss战
2. Boss出现，怪兽进入战斗模式
3. 玩家快速输入压力词生成对应情绪食物
4. 拖拽食物攻击Boss弱点部位
5. Boss血条归零，播放击败动画
6. 获得进化材料和特殊装饰

## 系统四：进化系统

### 进化规则
- 怪兽有4个进化槽位：头部、身体、手臂、尾巴
- 每个槽位根据吃掉最多的情绪类型进化出不同特征

### 进化形态表

| 部位 | 愤怒主导 | 焦虑主导 | 悲伤主导 | 烦躁主导 |
|------|----------|----------|----------|----------|
| 头部 | 火焰角 | 雷电耳 | 雨云帽 | 爆炸头 |
| 身体 | 熔岩纹路 | 电流皮肤 | 水晶身体 | 铠甲外壳 |
| 手臂 | 火拳 | 电爪 | 治愈之手 | 爆破臂 |
| 尾巴 | 火焰尾 | 闪电尾 | 彩虹尾 | 导弹尾 |

### 进化阶段
1. **幼年期**（0-50次喂食）：圆滚滚小球，大眼睛，小嘴
2. **成长期**（50-200次喂食）：开始长出特征，体型增大
3. **成熟期**（200-500次喂食）：特征明显，解锁特殊技能
4. **完全体**（500+次喂食）：独特形态，终极技能解锁

## 验证标准

1. **喂食流畅度**：拖拽喂食无卡顿，吞噬反馈即时（<100ms延迟）
2. **情绪转化**：4种情绪特效正确触发，视觉差异明显
3. **Boss战**：3个Boss均可正常战斗和击败，战斗节奏有爽感
4. **进化系统**：怪兽外观随饮食正确变化，至少12种组合形态
5. **双端兼容**：手机触屏和PC鼠标操作均流畅
6. **减压效果**：核心循环（输入压力→喂食→爽感反馈）体验顺畅

## 假设与约束

- MVP阶段使用占位美术素材（简单几何形状+颜色），后期替换正式美术
- 情绪识别基于关键词匹配，不使用NLP/AI
- 进化系统MVP实现3-4种基础形态组合，完整版扩展更多
- Boss战MVP实现1个Boss，完整版3个
- 音效使用免费素材库，后期可替换原创音效
